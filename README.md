# cli-gestor-productos-fakestore
Herramienta de interfaz de línea de comandos (CLI) desarrollada en Node.js para la pre-entrega del curso de Talento Tech. Permite gestionar dinámicamente un catálogo de productos (CRUD: consultar, crear y eliminar) interactuando directamente con la API REST de FakeStore mediante peticiones asíncronas y manipulación de argumentos en la terminal.
